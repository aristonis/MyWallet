# MyWallet 1.0

Release notes for the 1.0 line. Each patch release is added at the top of this file.

## 1.0.0 (2026-08-28)

The first release: an offline personal finance tracker. Everything stays on your device, with no
account and no network access.

### Accounts and transactions
- Accounts of any type (cash, card, bank, savings) in any currency, each with an opening balance.
  Archive an account you no longer use; delete one that has no transactions.
- Record income, expenses and transfers, including transfers between currencies. Edit or delete
  any entry, and undo a delete.

### Currencies
- Pick a base currency when you start; every total is shown in it. The full list of current
  currencies is available.
- Set exchange rates yourself. Changing the base currency later keeps every recorded amount as it
  was.

### Categories and tracking
- Income and expense categories with sub-categories, editable from Settings.
- Tracking by day, week, month, year or all time, with income, spending, net and spending by
  category.

### Settings and data
- Back up all data to one JSON file and restore it later.
- Light, dark or system theme.
- Works right to left, and with large text sizes.

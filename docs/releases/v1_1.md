# MyWallet 1.1

Release notes for the 1.1 line. Each patch release (1.1.1, 1.1.2, ...) is added at the top of this
file.

## 1.1.0 (2026-10-08)

Tracking can now look at any period you choose, the transaction list can be filtered the same way,
and exchange rates can be fixed right where you enter an amount.

### Look at any period
- Tracking opens on the current month as before. The arrows step to the previous or next day,
  week, month or year, and tapping the dates opens a picker to jump to any day, month or year.
- The calendar button in the top bar picks a custom date range, from one day to as long as you
  like. Clear it to go back.
- Tracking stays on "now": if it shows the current month when the date changes, it moves on to the
  new month. A period you stepped back to stays where you left it.

### Income and sub-categories in Tracking
- Income is broken down by category, next to spending.
- A category with sub-categories opens to show each one, plus a "No sub-category" line for entries
  without one. The lines always add up to the category total.

### Filter the transaction list
- The Transactions list has the same date bar as Tracking. It still opens on everything; narrow it
  to a period or a custom range when you need to.
- When a range has no entries, the list says so instead of looking empty.

### Exchange rates on the transaction form
- When an entry involves a currency other than your base currency, the form shows its rate, for
  example "1 USD = 13000 SYP", and lets you change it there instead of going to Settings.
- Under the amount you see what it is worth in your base currency, for example "2 $" becomes
  "≈ 26,000 SYP".
- A transfer between two currencies shows the rate between them and exactly how much arrives.
- New Settings switch, "Save rates I enter on transactions", on by default. When it is on, a rate
  you type becomes the saved rate. When it is off, a typed rate applies to that transfer only.
- A rate you type is only saved once the entry is accepted, so a refused entry never changes your
  rates.

### Other changes
- New launcher icon: a closed ledger with a mint ribbon.
- Reports and the transaction list read only the dates on screen, so long histories load faster.

### Upgrading
- Upgrading from 1.0 keeps every record. The database updates itself on first launch.
- Export a backup from Settings before you update, as with any update.
- A backup made in 1.1 restores in 1.0 as long as the rate switch was never turned off.

### Known issue
- If you save an entry dated outside the period the Transactions list is narrowed to, it only
  appears once the list covers that date.
